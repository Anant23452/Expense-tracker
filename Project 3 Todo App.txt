# 📚 React Concepts Learned

## 1. useState

State stores data that changes.

```jsx id="g2gyne"
const [task, setTask] = useState("");
const [todos, setTodos] = useState([]);
const [filter, setFilter] = useState("all");
```

### When to use?

Whenever UI changes after user interaction.

Examples:

- Input
- Counter
- Todo List
- Theme
- Login Status


# 📚 Filtering

State

```jsx id="ceswm8"
const [filter,setFilter]=useState("all");
```

Possible values

``` id="apzy1k"
"all"

"active"

"completed"
```

---

Logic

``` id="bl2f4k"
Original Todos

↓

Apply Filter

↓

filteredTodos

↓

Render
```

Code

```jsx id="alhbdf"
let filteredTodos=[];

if(filter==="all")
{
    filteredTodos=todos;
}
else if(filter==="active")
{
    filteredTodos=todos.filter(todo=>!todo.completed);
}
else
{
    filteredTodos=todos.filter(todo=>todo.completed);
}
```

Render

```jsx id="eio0wz"
filteredTodos.map(...)
```

# 🧠 DSA Revision Kit (Your Preferred Style)

## Todo App Revision

**Pattern:** React State Management + CRUD Operations

### Add
- **Method:** Spread Operator
- **Idea:** Create a new array with old items + new item.
- **Complexity:** `O(n)`

### Delete
- **Method:** `filter()`
- **Idea:** Keep every item except the one to remove.
- **Complexity:** `O(n)`

### Update
- **Method:** `map()` + Object Spread
- **Idea:** Return a new object only for the item that changes.
- **Complexity:** `O(n)`

### Filter Display
- **Method:** `filter()`
- **Idea:** Don't change the original array—derive a new array for rendering.
- **Complexity:** `O(n)`

### Common Mistakes
- ❌ Mutating state (`push()`, `todo.completed = true`)
- ❌ Passing an object to `setTodos` instead of an array
- ❌ Forgetting `return` inside `map()`
- ❌ Rendering `todos` instead of `filteredTodos`
- ❌ Missing `onChange` for controlled checkboxes

# 🎯 Final Note

You have now completed **three React projects**. More importantly, you've learned the reasoning behind state updates:

- **Add** → Spread (`...`)
- **Delete** → `filter()`
- **Update** → `map()`
- **Display subset** → `filter()`
- **Render** → `map()`

These patterns are the foundation of React. You'll reuse them in shopping carts, user dashboards, note-taking apps, admin panels, and API-based applications.

One improvement we'll make in the future is to use **unique IDs** instead of array indexes. That will fix the bug where deleting or toggling items while a filter is active can affect the wrong todo. This is how production React apps are typically built.
